# Informativa sulla privacy di Tabby

*Ultimo aggiornamento: 15 novembre 2026*

Tabby è un'applicazione per Windows che funziona sul tuo PC. **Non esiste alcun server di Tabby**: nessun dato viene inviato allo sviluppatore né a terzi.

## Dove stanno i tuoi dati

Note, immagini e impostazioni restano sul tuo computer, in `%APPDATA%\it.pisco.tabby\`. Tabby non ha account, non raccoglie statistiche e non usa servizi di analisi.

## Sincronizzazione tra PC e liste condivise (facoltative)

Se scegli una cartella di sincronizzazione (per esempio in Google Drive, OneDrive o Dropbox), Tabby vi scrive le tue note perché gli altri tuoi PC le leggano; il servizio cloud le conserva secondo le sue regole. Tabby non manda nulla allo sviluppatore. Puoi cifrare la cartella con una frase segreta: allora il servizio cloud vede solo dati illeggibili. Le copie per il telefono (se attive) sono file di testo leggibili. Nelle liste condivise con altre persone finiscono solo le note di quella cartella, mai quelle protette da PIN.

## Aggiornamenti

Dalle impostazioni Tabby può controllare se esiste una nuova versione contattando le pagine pubbliche delle release su GitHub. Non invia alcun dato personale.
